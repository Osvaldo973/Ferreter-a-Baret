# 🛠️ Ferretería Baret — Sitio Web Oficial & Panel de Control

Bienvenido al repositorio oficial de **Ferretería Baret**, ubicada en **Los Frailes 2do, Santo Domingo Este, República Dominicana**. Este proyecto es una plataforma web moderna, rápida e interactiva para la consulta de productos de construcción, plomería, herramientas y servicios para el hogar.

---

## 📌 Características Principales

- 🛒 **Catálogo de Productos en Tiempo Real**: Visualización dinámica de productos, marcas, ofertas y recomendados.
- 📱 **Pedidos Directos por WhatsApp**: Generación automática de cotizaciones y facturas enviadas directamente al WhatsApp del negocio (`(809) 598-8068`).
- ⚡ **Base de Datos en la Nube con Supabase**: Sincronización instantánea de productos e inventario.
- 🔐 **Panel de Administración (`/admin.html`)**: Gestión CRUD (Crear, Leer, Actualizar y Eliminar) de productos, marcas y administradores.
- 🚀 **Despliegue Continuo en Vercel**: Alojamiento optimizado con despliegue automático desde GitHub.
- 🎯 **Optimización SEO y Redes Sociales**: Meta etiquetas Open Graph, schema `HardwareStore` en JSON-LD, `sitemap.xml` y `robots.txt`.

---

## 🛠️ Tecnologías Utilizadas

- **Frontend**: HTML5 Semántico, Vanilla CSS3 (Variables, Grid, Flexbox, Animations), JavaScript ES6+.
- **Backend / Database**: [Supabase](https://supabase.com) (PostgreSQL & Client SDK v2).
- **Hosting**: [Vercel](https://vercel.com).
- **Iconos y Fuentes**: Font Awesome 6, Google Fonts (Inter & Montserrat).
